# Sales Performance Dashboard

An interactive **Sales Performance Dashboard** built using **Microsoft Power BI** to analyse sales, profit, orders, product performance, and regional trends using the Sample Superstore dataset.

## Project Overview

This project explores sales data to identify business trends, evaluate profitability, and understand performance across different product categories, customer segments, and regions.

## Tools & Technologies

- **Power BI** – Interactive dashboards and data visualisation
- **Power Query** – Data cleaning and transformation
- **DAX** – Measures and KPI calculations
- **Excel** – Source dataset
- **GitHub** – Project documentation and version control

## Dashboard Pages

### Page 1: Sales Overview
- Total Sales
- Total Orders
- Total Quantity
- Total Profit
- Profit Margin
- Sales by Category
- Sales by Region
- Monthly Sales Trend
- Interactive slicers

### Page 2: Product & Customer Analysis
- Profit by Sub-Category
- Sales by Product
- Sales and Profit by Ship Mode
- Sales by Customer
- Product Performance Matrix
- Scatter Plot Analysis

### Page 3: Regional Analysis
- Regional sales and profit comparisons
- Geographic performance analysis
- Regional trends and business insights

## Data Preparation

- Checked missing and invalid values
- Reviewed data types
- Checked duplicate Row IDs and exact duplicate rows
- Validated sales, quantity, and discount values
- Created date-related columns for time-based analysis

## Key Objectives

- Identify top-performing products and categories
- Compare sales and profitability across regions
- Analyse monthly sales trends
- Understand customer and shipping performance
- Support data-driven business decisions
